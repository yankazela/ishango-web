## 概要

米国からドイツへの移住は、個人が直面しうる最も複雑な国際税務状況の一つです。米国は世界でも2か国だけ（エリトリアとともに）、**居住地に関係なく市民の世界収入に課税**している国のうちの一つです。

つまり、ドイツに移住しても、税制をそのまま切り替えるわけではありません — **両方の制度に適用される**ことになります。

---

## ステップ1：海外在住者としての米国税務義務の理解

### 米国は市民を世界規模で課税する

ドイツに移住した後も以下が必要です：

- 毎年**米国連邦税務申告書（Form 1040）**を提出する
- ドイツの給与、フリーランス収入、投資、賃貸収入を含む**すべての世界収入を申告**する
- 年間のどかの時点で$10,000を超える外国銀行口座がある場合は**FBAR（FinCEN 114）**を提出する
- 特定の閾値を超える外国金融資産がある場合は**FATCA（Form 8938）**を遵守する

### FBARの提出閾値

| 申告ステータス | 閾値 |
|---|---|
| 独身（海外） | $200,000（年末）/ $300,000（任意の時点） |
| 既婚共同申告（海外） | $400,000 / $600,000 |

## ステップ2：ドイツの税務居住の確立

### ドイツの税務居住者になるのはいつ？

以下の場合にドイツの税務居住者になります：

- ドイツで**主たる居所（Hauptwohnsitz）**を登録する（Anmeldung）
- または1暦年にドイツで**183日以上**滞在する

居住者になると、**世界収入**に対してドイツ所得税を支払う義務が生じます — 米国が課税しようとしている同じ収入です。

### ドイツの税率区分（2026年）

| 収入の範囲 | 税率 |
|---|---|
| €11,604まで | 0% |
| €11,605 – €17,005 | 14〜24% |
| €17,006 – €66,760 | 24〜42% |
| €66,761 – €277,825 | 42% |
| €277,826以上 | 45% |

## ステップ3：米国・ドイツ租税条約

米国とドイツは**二国間租税条約**（二重課税防止協定またはDTA）を持っており、各種類の収入に対してどちらの国が優先課税権を持つかを決定します。

### 主要な条約規定

| 収入の種類 | 優先課税権 |
|---|---|
| 給与収入 | ドイツ（仕事が行われる場所） |
| 自営業 | ドイツ（恒久的施設が存在する場合） |
| 配当 | 共有（軽減源泉徴収税率が適用） |
| 利子 | 軽減源泉徴収 |
| 譲渡所得（不動産） | 不動産が所在する場所 |
| 年金 | 出所による（国家 vs. 民間） |

### 条約は米国の課税を排除しない

条約は控除と免除を通じて**二重課税を防ぎます**が、米国の確定申告義務を排除するわけではありません。

## ステップ4：二重課税の回避

### 外国税額控除（Form 1116）

最も一般的な方法です。ドイツで支払った税金を米国の税額から控除します。

**仕組み：**
- ドイツで€80,000を稼ぐ
- ドイツの所得税約€20,000を支払う
- 米国の確定申告で収入を申告する
- ドイツに既に支払った€20,000の控除を申請する
- 米国の税額が軽減される（多くの場合ゼロに）

### 海外稼得収入除外（Form 2555）

**物理的存在テスト**（330日海外）または**実質的居住テスト**に合格した場合、**$126,500**（2026年）までの稼得収入を米国課税から除外できます。

**重要：** 同じ収入に対して除外と控除の両方を使用することはできません。状況に基づいて慎重に選択してください。

## ステップ5：社会保障と医療

### 社会保障トータリゼーション協定

米国とドイツは社会保障の二重加入を防ぐための**トータリゼーション協定**を持っています。一般的に：

- 米国企業に雇用されドイツに一時的に（5年未満）赴任する場合：米国の社会保障のみ支払う
- ドイツの雇用主のもとで働く場合：ドイツの社会保険料を支払う

### ドイツの社会保険料（従業員負担分 約2026年）

| 保険の種類 | 割合 |
|---|---|
| 健康保険 | 約7.3% + 追加保険料 |
| 年金保険 | 9.3% |
| 失業保険 | 1.3% |
| 介護保険 | 1.7〜2.0% |
| **合計** | **約20%** |

## ステップ6：ドイツ固有の考慮事項

### 税番号（Steuernummer）と税務識別番号（Steueridentifikationsnummer）

- 地元の**Finanzamt（税務署）**に登録してSteuernummerを受け取る
- 恒久的なSteueridentifikationsnummer（11桁）はAnmeldung後に自動的に発行される

### ドイツの確定申告

- 従業員の場合は一般的に**任意**ですが、フリーランサー、自営業者、複数の収入源がある人には**義務**
- 締め切り：翌年の7月31日（税務アドバイザーを利用する場合は延長可能）
- Steuerberater（税務アドバイザー）への依頼は米国在住者に強く推奨

## ドイツの米国在住者のよくある落とし穴

| 落とし穴 | リスク |
|---|---|
| 米国の確定申告を提出しない | ペナルティ、パスポート更新権の喪失 |
| FBARの期限を見逃す | 違反1件につき$10,000以上の罰金 |
| 除外と控除の方法を誤って選ぶ | 不必要に多くの税金を支払う |
| ドイツの年金保険料を無視する | 退職給付を逃す |
| ドイツの銀行口座を申告しない | FATCAのコンプライアンス問題 |
