## Aperçu

Pour les expatriés britanniques et les professionnels internationaux, le choix entre rester au Royaume-Uni et s'installer au Portugal est devenu l'une des décisions financières les plus discutées ces dernières années. L'ancien régime **RNH (Résident Non Habituel)** du Portugal offrait d'importants avantages fiscaux qui ont attiré des dizaines de milliers d'expatriés — mais il a été réformé en 2024.

Ce guide compare le **système fiscal britannique** avec le **nouveau régime IFICI du Portugal** (qui a remplacé le NHR) pour vous aider à décider lequel convient le mieux à votre situation.

---

## Le système fiscal britannique (2026)

### Impôt sur le revenu

Le Royaume-Uni utilise un système progressif avec un abattement personnel.

| Tranche de revenus | Taux |
|---|---|
| Jusqu'à £12 570 | 0 % (Abattement personnel) |
| £12 571 – £50 270 | 20 % (Taux de base) |
| £50 271 – £125 140 | 40 % (Taux supérieur) |
| Au-delà de £125 140 | 45 % (Taux additionnel) |

> Note : L'abattement personnel est réduit au-dessus de £100 000 — il diminue de £1 pour chaque £2 gagnée au-delà de ce seuil.

### Impôt britannique sur les plus-values (2026)

| Type d'actif | Taux de base | Taux supérieur |
|---|---|---|
| Propriété résidentielle | 18 % | 24 % |
| Autres actifs | 10 % | 20 % |

### Impôt britannique sur les dividendes

| Tranche | Taux sur dividendes |
|---|---|
| De base | 8,75 % |
| Supérieure | 33,75 % |
| Additionnelle | 39,35 % |

### Imposition des pensions au Royaume-Uni

- La pension d'État est un revenu imposable
- Pensions privées : 25 % du capital exonéré d'impôt, le reste imposé comme revenu
- Plafond d'épargne retraite (Lifetime Allowance) supprimé (2024)

## Le régime IFICI du Portugal (2026)

Le régime **IFICI** a remplacé le NHR en janvier 2024.

### Qui est éligible à l'IFICI ?

Pour être éligible, vous devez :

1. **Ne pas avoir été résident fiscal portugais** au cours des 5 années précédentes
2. **Exercer une activité qualifiante** — principalement dans les domaines de la tech, R&D, scientifique ou de professions hautement qualifiées

### Taux d'imposition IFICI

Les revenus éligibles sont imposés à un **taux forfaitaire de 20 %** pour une période de **10 ans**.

| Type de revenu | Taux IFICI |
|---|---|
| Revenus d'emploi (activité qualifiante) | 20 % |
| Revenus d'activité indépendante (activité qualifiante) | 20 % |
| Revenus portugais non qualifiants | Taux standards (jusqu'à 48 %) |

### Tranches d'imposition standard au Portugal (2026)

| Tranche de revenus | Taux |
|---|---|
| Jusqu'à 7 703 € | 13,25 % |
| 7 703 € – 11 623 € | 18 % |
| 11 623 € – 16 472 € | 23 % |
| 16 472 € – 21 321 € | 26 % |
| 21 321 € – 27 146 € | 32,75 % |
| 27 146 € – 39 791 € | 37 % |
| 39 791 € – 51 997 € | 43,5 % |
| 51 997 € – 81 199 € | 45 % |
| Au-delà de 81 199 € | 48 % |

### Revenus étrangers sous l'IFICI

Contrairement à l'ancien NHR, le régime IFICI **n'exonère pas automatiquement les revenus étrangers**. Les revenus étrangers sont généralement imposés aux taux standards portugais, sauf s'ils bénéficient d'une convention fiscale.

## NHR historique (toujours applicable pour les résidents ayant des droits acquis)

Si vous avez obtenu le statut NHR **avant janvier 2024**, vos avantages sont protégés pour votre période initiale de 10 ans :

| Type de revenu | Taux NHR historique |
|---|---|
| Revenus d'emploi (qualifiants) | 20 % forfaitaire |
| Pensions étrangères | 10 % forfaitaire |
| Dividendes et intérêts étrangers | 0 % (exonéré) |
| Revenus locatifs étrangers | 0 % (exonéré) |
| Plus-values sur actifs étrangers | 0 % (exonéré) |

## Comparaison directe

### Pour les professionnels salariés

| Scénario | Royaume-Uni | Portugal (IFICI) |
|---|---|---|
| Salaire 80 000 € | ~32 % taux effectif | 20 % forfaitaire |
| Salaire 150 000 € | ~42 % taux effectif | 20 % forfaitaire |
| Revenus de dividendes | 33,75 %+ | Taux standards (sauf NHR historique) |

**Gagnant pour les professionnels salariés :** Portugal (IFICI), surtout au-dessus de £50 000.

---

### Pour les retraités

| Scénario | Royaume-Uni | Portugal (NHR historique) |
|---|---|---|
| Pension étrangère (40 000 €) | Progressif (jusqu'à 40 %) | 10 % forfaitaire |
| Pension d'État britannique | Revenu imposable | Imposé selon convention (généralement 10 %) |
| Revenus d'investissement | 20–39,35 % (dividendes) | 0 % (NHR historique) |

**Gagnant pour les retraités :** Portugal avec NHR historique de très loin. Les nouveaux candidats IFICI doivent évaluer soigneusement.

---

### Pour les télétravailleurs et freelances

| Scénario | Royaume-Uni | Portugal (IFICI) |
|---|---|---|
| Revenus freelance 60 000 € | ~30–35 % effectif | 20 % forfaitaire (si activité qualifiante) |
| Plusieurs clients, portée mondiale | Complexité élevée | Complexité moyenne |
| Cotisations sociales | NICs ~10–13 % | Cotisations SS ~11 % |

**Gagnant :** Portugal pour les freelances exerçant des activités qualifiantes.

---

### Pour les plus-values

| Scénario | Royaume-Uni | Portugal |
|---|---|---|
| Gain sur vente immobilière £100 000 | 18–24 % | 28 % standard |
| Gain sur actions £50 000 | 10–20 % | 28 % standard |
| NHR historique — actifs étrangers | N/A | 0 % (exonéré) |

**Gagnant :** Royaume-Uni pour les plus-values (surtout sur les actions), sauf si vous bénéficiez du NHR historique.

## Avantages et inconvénients

### Portugal — Avantages
- Impôt forfaitaire de 20 % sur les revenus qualifiants pendant 10 ans
- Coût de la vie moins élevé (hors Lisbonne)
- Climat et qualité de vie
- Résidence UE, espace Schengen
- NHR historique très attractif pour les résidents ayant des droits acquis

### Portugal — Inconvénients
- Qualification IFICI limitée à certaines catégories professionnelles
- Revenus étrangers non automatiquement exonérés sous le nouveau régime
- Bureaucratie parfois lente
- Prix immobiliers en hausse à Lisbonne/Porto

### Royaume-Uni — Avantages
- Pas de relocalisation nécessaire
- Pas besoin de se qualifier pour un régime spécial
- Taux de plus-values inférieurs sur les actions
- Cadre juridique solide, langue familière

### Royaume-Uni — Inconvénients
- Imposition progressive jusqu'à 45 %
- Coût de la vie élevé (surtout à Londres)
- Pas de fiscalité territoriale — revenus mondiaux imposés
- Taux élevés sur les dividendes
