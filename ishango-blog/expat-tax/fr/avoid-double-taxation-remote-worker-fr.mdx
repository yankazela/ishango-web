## Aperçu

Travailler à distance depuis l'étranger crée un véritable labyrinthe fiscal que des millions de travailleurs naviguent en 2026. Le problème central : **deux pays peuvent légitimement revendiquer le droit d'imposer les mêmes revenus** — le pays de votre employeur et le pays où vous vivez.

La bonne nouvelle : il existe des mécanismes légaux bien établis pour s'assurer que vous payez des impôts une seule fois, pas deux.

---

## Qu'est-ce que la double imposition ?

La double imposition survient quand les mêmes revenus sont imposés par **deux juridictions distinctes** au cours de la même période.

**Exemple :**
- Vous êtes citoyen britannique et travaillez à distance depuis l'Espagne
- Le Royaume-Uni peut continuer à vous considérer comme résident fiscal britannique
- L'Espagne vous traite comme résident espagnol après 183 jours
- Les deux pays veulent imposer votre salaire → **double imposition**

---

## Méthode 1 : Les conventions fiscales (Conventions de double imposition)

L'outil le plus puissant contre la double imposition est une **convention fiscale bilatérale** (aussi appelée Convention de Double Imposition, CDI).

### Comment fonctionnent les conventions

Les conventions fiscales entre deux pays :

1. **Définissent la résidence** — établissent dans quel pays vous êtes « principalement » résident (règles de départage)
2. **Attribuent les droits d'imposition** — spécifient quel pays peut imposer quel type de revenu
3. **Prévoient des mécanismes de soulagement** — via des exonérations, crédits ou taux réduits

### Règles de départage (hiérarchie typique d'une convention)

Si vous semblez résident dans les deux pays, les conventions utilisent cet ordre :

| Priorité | Critère |
|---|---|
| 1 | Lieu de votre **foyer permanent** |
| 2 | Lieu de votre **centre des intérêts vitaux** (famille, travail, liens économiques) |
| 3 | Lieu de votre **séjour habituel** (test des 183 jours) |
| 4 | **Nationalité** |
| 5 | **Accord mutuel** entre autorités fiscales |

### Principales conventions pour les télétravailleurs

| Paire de pays | Convention existante ? |
|---|---|
| Royaume-Uni – Espagne | ✅ Oui |
| Royaume-Uni – Portugal | ✅ Oui |
| États-Unis – Allemagne | ✅ Oui |
| États-Unis – Royaume-Uni | ✅ Oui |
| Australie – Thaïlande | ✅ Oui |
| Allemagne – EAU | ✅ Oui |

## Méthode 2 : Le crédit pour impôt étranger

Si une convention fiscale n'élimine pas totalement la double imposition, le **crédit pour impôt étranger** vous permet de déduire les impôts payés à l'étranger de votre facture fiscale nationale.

### Comment ça fonctionne

1. Vous gagnez 60 000 € en travaillant à distance en Allemagne
2. L'Allemagne vous impose à hauteur de 12 000 €
3. Vous déposez une déclaration dans votre pays d'origine
4. Votre pays calcule un impôt de 15 000 € sur les mêmes revenus
5. Vous revendiquez le crédit de 12 000 € → vous payez seulement **3 000 €** à votre pays d'origine

### Limitations

- Le crédit est généralement plafonné à l'**impôt que vous auriez payé** dans votre pays d'origine
- Tous les types de revenus ne sont pas éligibles
- Certains pays n'accordent des crédits que pour les **impôts sur le revenu**, pas pour les cotisations sociales

## Méthode 3 : L'exclusion des revenus gagnés à l'étranger (États-Unis uniquement)

Pour les citoyens américains et les détenteurs de carte verte, l'**exclusion des revenus gagnés à l'étranger (FEIE)** permet d'exclure jusqu'à **126 500 $** (2026) de revenus d'activité étrangers de l'imposition américaine.

### Tests de qualification

Vous devez satisfaire l'un des critères suivants :

| Test | Exigence |
|---|---|
| Test de présence physique | 330 jours complets à l'étranger sur une période de 12 mois |
| Test de résidence de bonne foi | Année civile complète comme résident de bonne foi d'un pays étranger |

### Mise en garde importante

Vous **ne pouvez pas** revendiquer à la fois la FEIE et le crédit pour impôt étranger sur les mêmes revenus. Pour les hauts revenus dans des pays à forte imposition (Allemagne, France), le crédit pour impôt étranger est souvent plus avantageux.

## Méthode 4 : Planification adéquate de la résidence

La stratégie à long terme la plus efficace consiste à s'assurer d'être **sans ambiguïté résident fiscal dans un seul pays**.

### Rompre la résidence dans votre pays d'origine

Pour être traité comme non-résident par votre pays d'origine, vous devez généralement :

- [ ] Y passer moins de 183 jours par an
- [ ] Abandonner votre résidence principale (vendre ou louer)
- [ ] Transférer vos principaux comptes bancaires et investissements
- [ ] Vous désinscrire des registres locaux (le cas échéant)
- [ ] Résilier abonnements à des clubs, associations, salles de sport
- [ ] Mettre à jour votre permis de conduire au nouveau pays
- [ ] Couper les liens avec l'employeur du pays d'origine (ou créer une entité étrangère)

### Établir la résidence à l'étranger

Pour établir clairement une nouvelle résidence :

- [ ] S'inscrire officiellement (ex. Anmeldung en Allemagne, Padron en Espagne)
- [ ] Ouvrir des comptes bancaires locaux
- [ ] Obtenir un numéro d'identification fiscale local
- [ ] Louer ou acheter un logement dans le nouveau pays
- [ ] Déposer des déclarations fiscales locales dès la première année qualifiante

## Méthode 5 : Choisir des pays à fiscalité territoriale

Certains pays n'imposent que les **revenus générés sur leur territoire**, et non les revenus de source étrangère. S'installer dans un pays à fiscalité territoriale élimine un côté de l'équation de double imposition.

| Pays | Imposition des revenus étrangers |
|---|---|
| Panama | 0 % |
| Costa Rica | 0 % |
| Malaisie | 0 % (remises) |
| Singapour | 0 % (non remis) |
| Géorgie | 0 % (non remis) |
| EAU | 0 % (pas d'impôt sur le revenu) |
| Paraguay | 0 % |

## Cas particulier : Pays de l'employeur vs. lieu de travail

Si votre employeur est dans le Pays A mais que vous travaillez depuis le Pays B, les deux pays peuvent vouloir imposer vos revenus.

**Comment gérer cela :**
- Informez votre employeur de votre lieu de résidence — il peut avoir des obligations de retenue dans votre pays
- Vérifiez si votre employeur doit s'enregistrer comme employeur étranger dans votre pays
- Un arrangement à long terme peut nécessiter la création d'une entité locale ou le recours à un service d'Employer of Record (EoR)

- Vous êtes indépendant dans plusieurs juridictions
- Vous avez des investissements, propriétés ou plans de retraite dans plusieurs pays
